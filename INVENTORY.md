## REPO_A — Sliver v1.7.9

### Entrypoints

| Path | Kind | Role |
|---|---|---|
| `server/main.go` | `package main` | teamserver binary (`sliver-server`). Also hosts `daemon`, `operator`, `import-ca`, `export-ca`, `builder` subcommands. |
| `client/main.go` | `package main` | `sliver-client` interactive console (REPL). |
| `client/transport/*.go` | library | **the gRPC dial layer** used by every operator client. |
| `client/core/*.go` | library | client-side state: tunnels, socks, sessions watch. |
| `client/command/**` | library | one package per REPL command (thin wrappers over RPC). |

### Build system

- Go modules, `go 1.27.3` (module directive), built with `go build`.
- Protobuf generated by `protoc` into `protobuf/{rpcpb,clientpb,sliverpb,commonpb}`.
- `Makefile` targets for cross-compilation of implants; teamserver/client are
  plain Go builds.
- Release binaries (`sliver-server_linux-amd64`) are prebuilt and signed
  (`minisig`). We pin the release binary for the teamserver and the module source
  for the client library.

### Public surface (the only parts we call)

gRPC service `rpcpb.SliverRPC`, client interface `rpcpb.SliverRPCClient`
(230 methods). The subset this build uses, with exact signatures copied from
source into `NOTES.md`:

Client-side tunnel helper: `core.TunnelLoop(ctx, rpc)`, `core.GetTunnels().Start(id, sessionID) *TunnelIO`

### Dead code / not used

- `server/rpc/rpc-crackstations*.go`, `server/ai/*`, `client/command/crack/*`
  (crackstations, AI): present, not wired by us.
- `WebAssembly` extension runtime, `msf`, `wireguard` multiplayer transport:
  available but not exercised in M1–M5.
- `client/command/**` REPL wrappers: **we deliberately do not reuse them**, we
  call the RPC directly (SPEC §3: never shell out to `sliver-client`).
